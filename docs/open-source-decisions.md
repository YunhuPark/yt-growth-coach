# 오픈소스 선택 기록

기능을 직접 만들기 전에 쓸 만한 오픈소스를 비교하고, 고른 이유와 버린 이유를 남깁니다.

## 2026-11-12 음성 인식을 더 빠르게

- 필요: 영상 길이에 가깝게 걸리는 음성 인식 시간을 줄이기. 영상은 이 컴퓨터에서만 처리하고, Windows에서 설치 없이 돌아야 함.
- 측정(Intel Core Ultra X7 358H, 16스레드, whisper-small q8, 모델 준비된 상태): 앱 경로로 영상 길이의 **0.58~0.70배**(232초 음악 영상 135초). 엔진 단독은 0.46배. 처음 한 번은 모델을 불러오는 시간이 더해져 한 번은 0.96배까지 나옴.
- 설정으로는 빨라지지 않음: 스레드 수 16/8은 같거나 느렸고, 청크 겹침을 5초→2초로 줄이면 오히려 느려지고 결과가 불안정(107초, 글자 수 절반).
- 후보:
  - **whisper.cpp 직접**(MIT, 별 5만+, 활발): 릴리스에 **실행 파일이 없음**(사용자가 빌드해야 함) → 일반 사용자에게 부담. 버림.
  - **@fugood/whisper.node**(MIT, 10MB, 2026-11-09 갱신): 미리 빌드된 바인딩이라 설치는 쉽지만 **별 9개, 1.2.0-rc.2(출시 후보)**, 플랫폼별 네이티브 바이너리를 받아 실행함. 모델은 ggml-small-q5_1 약 190MB를 따로 받아야 함. 신뢰 신호가 약해 **시험 전 보류**.
  - smart-whisper(마지막 갱신 2024-10), whisper-node(2023-11): 오래됨. 버림.
  - 직접 구현: 하지 않음(추론 엔진을 새로 만드는 일).
  - 현재 유지(transformers.js + ONNX): 설치가 쉽고 이미 검증됨.
- 채택: **현재 엔진 유지**. 10분 영상에 약 6~7분이라 기다릴 만하고, 빨라진다는 근거(측정)가 없는 상태에서 신뢰가 약한 네이티브 바이너리를 들일 이유가 없음.
- 다시 볼 조건: 사용자가 긴 영상에서 속도를 실제로 불편해할 때. 그때는 @fugood/whisper.node를 설치해 같은 영상으로 속도와 글자 오류율을 재고(둘 다 나아질 때만 채택), 코드와 네이티브 바이너리의 출처를 읽은 뒤 결정.
- 라이선스 주의: 후보 모두 MIT. 모델 가중치(Whisper)는 MIT.

## 2026-11-06 얼굴 찾기

- 필요: 사람이 가까이 찍힐 때 몸 상자의 가운데가 얼굴과 달라서 자동 프레임이 얼굴을 자름.
- 후보: AdamCodd/YOLOv11n-face-detection(Apache-2.0 표기, 다운로드 56회) / OpenCV Zoo의 YuNet(MIT, 약 233KB) / 직접 구현
- 채택: **YuNet** — 이유: 라이선스가 확실하고(공식 모델 저장소) 작고 빠름(한 장 21~56ms).
- 버린 후보와 이유: AdamCodd 모델은 AGPL 계열인 Ultralytics YOLO11을 바탕으로 학습해 MIT 프로젝트에 쓰기에 라이선스가 확실하지 않음.
- 라이선스 주의: YuNet 폴더의 LICENSE는 MIT(Copyright 2020 Shiqi Yu). `THIRD_PARTY.md`에 적음.
- 적용 후 확인: 같은 웹캠 영상의 렌더 8장 모두 얼굴이 가운데(몸 상자만 쓸 때는 6장, 그것도 손으로 맞춘 뒤).

## 2026-11-05 음성 인식 정확도

- 필요: 작은 소리의 한국어 음성을 더 정확하게 받아 적기.
- 후보: whisper-small(현재) / whisper-large-v3-turbo(ONNX, 약 760MB) / 클라우드 음성 인식 / 직접 구현
- 채택: **whisper-small 유지** — 이유: 정답이 공개된 한국어 낭독 음성(Google FLEURS, CC BY 4.0) 6개에서 글자 오류율 4.1%, 소리를 −42 dB로 낮춰도 4.5%. 큰 모델은 웹캠 영상에서 나아지지 않았고(“공식을 갔어” 등) 더 느림.
- 버린 후보와 이유: turbo(이득 없음, 760MB, 느림), 클라우드(영상 소리가 밖으로 나가는 방식 변경이 필요하고 정확도 상승 근거 없음; 자막 시간 정보가 없는 모델도 있음).
- 적용 후 확인: 위 오류율. 조용한 곳의 낭독 음성이라 음악·잡음·대화가 섞인 영상의 정확도는 모름.
